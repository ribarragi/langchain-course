What are AI agents
Uses LLMs as a reasoning element to decide what actions to take and then executes those actions
Agents dynamically determine steps to take or tools to use to response specific questions
The LLM is deciding whats to be done next

ReAct Agent architecture

Need tools: abilties we give the LLM
Iterative loop of thinking - action - tool - observtion - thinking until task is completed

Tools:
Function that an agent can execute, any function we want.
We write the internal implementation of the function.
The easiest way is to use the @tool decorator and template in langchain documentation: docstrings, typestrings, ...
Note that the typestrings, argument names, docstrings of function are VERY important: under the hood, the LLM uses these argument and descriptions
to decide to call or not the tools

main_3.py has a very very simple function that is calling chatgpt and not doing much but gives a good idea if each
and when and how the llm is called and what for.
In this case the LLM decided which tool to use and which arguments.
And we have an agent who runs this stuff.
Remember we can always go to smith.langchain.com to see the traces of the calls.
You can see in the trace the tools the input, the putput, the model...
