Theory of ReAct (the agent loop)
First user query to the agent
Agent processes and returns answer

First step of agent: decide what tool to use or return answer: Thought (LLM thinking after we send it the query and all the tools and information
that the agent has at its disposal). The output is the next thing to execute: the tool call or an answer if it already has enough information.
LLM decides what tool to use: uses function features.
We then take the agents decision and execute that action, that will happen in our application: LLM will give us Whattool to use and with what areguments,
we take that and run it in our agent application.
The result of the tool is referred to as Observation.
Now we take feed all back to the llm, the outut and the history (Trackpad). The agent has the query, the info about the product price. So in the 
second iteration of the LLM, it knows that it must now apply a different tool. So we execute that decision in out application and we get 
another Observation.
In the third iteration of the agent, we send the LLM the query, the first output, the second output, what tools it executed, the whole history, Sothe agent has enough
information to decide not to use another tool, but to provide the answer.

Why does messages start with SystemMessage first?
Order matters. The LLM reads messages in sequence, so:
SystemMessage first — sets the rules before anything else
HumanMessage second — the actual question
If you put HumanMessage first the LLM might start reasoning before it knows the rules.

messages is just a list that represents the conversation so far. 

messages = [
        SystemMessage(
            content=(
              "..."
            )
        ),
        HumanMessage(content=question),
    ]

Every message has a role (System, Human, AI, Tool) and content. 
The LLM reads this entire list every time it's called to understand the full context.

Think of messages like a briefing packet you hand to a new employee:
SystemMessage = the employee handbook and rules
HumanMessage = the customer's request

This part: ai_message = llm_with_tools.invoke(messages)
Every iteration sends the entire conversation history to the LLM. 
The LLM reads everything — system rules, the question, any tool results so far — and decides what to do next. 
It returns an ai_message which contains either:
A tool call — "I need to call get_product_price"
A final answer — "The price with discount is $1,104.99"


This part: tool_calls = ai_message.tool_calls
Extracts the tool call decisions from the LLM's response. This is a list that looks like:
[{"name": "get_product_price", "args": {"product": "laptop"}}]

This part and the 3 following: tool_name = tool_call.get("name")
Are just fetching the tool called from the llm. So the llm decided it will call a tool, now we need to 
get what tool it decided to use (if any) and then we do this: tool_to_use = tools_dict.get(tool_name)
to get the actual python function from our local dictionary of functions looking for it usingits name 
so we can go ahead and comply with llms decision to use a tool. in this example we are inly doing the first one
it could be that there are more than 1 that the llm decided to use
